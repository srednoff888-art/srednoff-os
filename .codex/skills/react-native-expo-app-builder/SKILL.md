# React Native Expo App Builder

## Decisions

- Confirm Expo/React Native versions, managed/native boundaries, navigation, and target devices.
- Model async state, safe areas, permissions, and offline recovery using existing dependencies.

## Acceptance

Build and test device workflows and release configuration; disclose emulator-only coverage.

## Constraints

- Do not assume web-only libraries work on native targets.
