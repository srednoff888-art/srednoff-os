# Internal Linking Ia

## Decisions

- Map page purpose, intent clusters, navigation depth, and orphan URLs using crawl evidence.
- Use contextual links and descriptive anchors; avoid automated links that create irrelevant or duplicate paths.

## Acceptance

Verify target status/canonical consistency and compare crawl reachability.

## Constraints

- Do not create unnatural linking patterns solely for search engines.
