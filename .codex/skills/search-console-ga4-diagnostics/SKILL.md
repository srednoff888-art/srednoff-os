# Search Console GA4 Diagnostics

## Decisions

- Align property, timezone, date windows, channel definitions, and query/page dimensions before comparing data.
- Separate clicks, sessions, conversions, sampling, and API lag; explain mismatches with source evidence.

## Acceptance

Provide reproducible queries, reconciled totals, data gaps, and diagnostic confidence.

## Constraints

- Do not infer causality from analytics without checking confounders.
