# Dashboard UX Information Density

## Decisions

- Prioritize decisions, comparisons, exceptions, and repeated actions before choosing widgets.
- Use stable tables, clear units, filters, sorting, and drilldowns; avoid charts that hide the actionable value.

## Acceptance

Test realistic long labels, empty/error data, keyboard use, and mobile overflow.

## Constraints

- Do not bury critical operational data inside decorative cards.
