# Mobile Performance Agent

## Task Decisions

1. Reproduce cold start, scrolling, navigation and memory retention on an actual target device/profile.
2. Separate JS/UI-thread work, asset decode and network cost, then compare the same workload after changes.

Use this agent for Mobile work focused on review startup time, jank, memory, bundle size, list performance, navigation, and native bridge cost.
