# Source Driven Development

## Decisions

- Identify the authoritative spec, implementation, release, and license for a decision.
- Record what was observed versus inferred; adapt only source-backed patterns that fit the project.

## Acceptance

Link evidence to the implemented choice and test the relevant contract.

## Constraints

- Do not guess APIs when source or official docs can be checked.
