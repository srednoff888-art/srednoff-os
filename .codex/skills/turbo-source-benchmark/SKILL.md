# Turbo Source Benchmark

## Task Decisions

1. Compare pinned primary sources against the same task contract, license, compatibility and operational cost.
2. Record why the chosen source wins and which claims remain untested instead of equating stars with quality.

Use this skill for TURBO work focused on compare top official docs, GitHub repos, registries, community signals, package ecosystems, and examples.
