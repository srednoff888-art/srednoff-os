# Frontend Design System

## Decisions

- Inventory existing primitives and tokens before proposing a new component layer.
- Define semantic variants and state contracts; keep exceptions explicit rather than multiplying styles.

## Acceptance

Validate representative forms, navigation, dialogs, tables, and responsive layouts.

## Constraints

- Do not invent a design system when an existing one is present in the repo.
