# search console performance triage

## Task Decisions

1. Segment a change by query, page, country and device against comparable seasonal windows.
2. Check indexing, releases and demand shifts before attributing lost clicks to one ranking change.

## Domain Focus

triage Search Console impressions, clicks, queries, pages, device, country, and anomaly evidence.

## Official Sources

https://developers.google.com/search/docs | https://schema.org/docs/gs.html

## Guardrails

- Capture baselines before making recommendations that affect crawl, indexation, or traffic.
- Do not delete pages, publish redirects, change robots, or alter canonicals without explicit approval.
- Separate observed evidence from inferred search-impact estimates.
