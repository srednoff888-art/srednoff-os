# App Store Aso Metadata

## Decisions

- Build metadata from the actual product, locale, user vocabulary, and current store constraints.
- Avoid unsupported claims, keyword stuffing, and screenshots of unavailable features.

## Acceptance

Check each locale's limits, links, privacy labels, screenshots, and target build.

## Constraints

- Do not use misleading claims or competitor trademarks improperly.
