# Serp Feature Rich Result Planner

## Task Decisions

1. Identify the relevant current search feature and the page's actual eligibility/content evidence.
2. Prefer one accurate supported markup path; do not invent FAQ/review/product data to chase a SERP feature.

Use this skill for SEO tasks focused on SERP features, rich result eligibility, schema opportunities, result type strategy.

## Guardrails

- Do not promise rich results that search engines do not guarantee.
- Do not perform destructive, paid, production, publishing, account-changing, or externally visible actions without explicit user confirmation.
- Do not expose secrets, private keys, tokens, cookies, private analytics, personal data, or confidential business data.
- If validation is impossible, state why and provide a concrete manual verification path.
