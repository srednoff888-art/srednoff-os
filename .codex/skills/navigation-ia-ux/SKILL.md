# Navigation Ia UX

## Decisions

- Map user tasks, content hierarchy, location awareness, and back/deep-link behavior.
- Keep labels unambiguous and navigation accessible; avoid hiding frequent actions behind decorative structure.

## Acceptance

Test finding, completing, and returning from critical tasks on mobile and desktop.

## Constraints

- Do not create navigation that only works for the happy path.
