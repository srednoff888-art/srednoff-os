# Structured Data Schema Org

## Decisions

- Choose schema types/properties that describe visible page content and actual entities.
- Validate syntax and current search-engine eligibility; avoid unsupported claims or hidden review data.

## Acceptance

Test rendered markup and content consistency; rich-result visibility remains an observation.

## Constraints

- Do not mark up content that is not visible or truthful on the page.
