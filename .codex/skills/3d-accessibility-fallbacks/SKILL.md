# 3D Accessibility Fallbacks

## Task Decisions

1. Provide the same product information and primary action outside the canvas; make object selection and camera controls operable without dragging.
2. Test keyboard-only use, reduced motion, WebGL denial and screen-reader reading order; a decorative poster is not an equivalent configurator.

Use this skill for 3D Web work focused on provide static fallback, alt content, keyboard interaction, reduced motion, and low-power device paths.
