# Visual Hierarchy Layout Review

## Decisions

- Identify the primary user task and compare heading, action, density, and reading-order priorities.
- Use realistic content and screenshots; preserve accessible semantics and existing design tokens.

## Acceptance

Report concrete layout defects with viewport/context and verify their corrections.

## Constraints

- Do not use hero-scale type inside compact panels or dashboards.
