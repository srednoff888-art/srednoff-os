# Context Engineering

## Decisions

- Map task ownership, source files, contracts, and validation commands before choosing context.
- Load narrow references on demand; preserve decisions and unresolved work across compaction without copying transcripts.

## Acceptance

Check that the handoff contains enough evidence to resume and excludes unrelated or secret-bearing data.

## Constraints

- Do not load unrelated context that bloats the working set.
