# Spec Driven Development

## Decisions

- Turn the requested behavior into observable inputs, outputs, errors, and acceptance criteria.
- Resolve ambiguous contracts before broad implementation; keep design choices tied to requirements.

## Acceptance

Test each acceptance criterion and report uncovered requirements.

## Constraints

- Do not expand scope beyond the agreed spec without recording assumptions.
