# Figma To Code Implementation

## Decisions

- Read approved frame context, tokens, component mappings, and asset rights before implementation.
- Adapt to the repository's component API, responsive layout, semantics, and hydration boundaries.

## Acceptance

Compare rendered screenshots and test keyboard/state behavior against the approved design.

## Constraints

- Do not ignore existing design-system primitives in the codebase.
