# Creative Landing Page Builder

## Decisions

- Translate the offer, audience, proof, objections, and primary conversion into a coherent page flow.
- Use relevant assets with provenance; implement real forms and async states rather than placeholder interactions.

## Acceptance

Test mobile/desktop hierarchy, keyboard flow, form recovery, page speed, and message match.

## Constraints

- Do not ship generic gradient-only pages when real/product visuals are needed.
