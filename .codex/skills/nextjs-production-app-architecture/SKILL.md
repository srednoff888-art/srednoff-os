# Nextjs Production App Architecture

## Decisions

- Confirm installed Next.js version and server/client/runtime boundaries before choosing APIs.
- Make caching, revalidation, data ownership, error boundaries, and auth behavior explicit.

## Acceptance

Build and test representative routes, streaming/error states, hydration, and unauthorized access.

## Constraints

- Do not add client components or dynamic rendering without need.
