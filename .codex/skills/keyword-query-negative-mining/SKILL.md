# Keyword Query Negative Mining

## Decisions

- Compare actual search terms with keyword intent, conversions, match type, and lag-aware spend.
- Draft exclusions with scope and examples; check that profitable or ambiguous queries are not blocked.

## Acceptance

Report source query rows, confidence, expected effect, and reversible change scope.

## Constraints

- Do not add broad negatives that can block valuable traffic without review.
