# iOS Swiftui App Builder

## Decisions

- Model state ownership, async loading, navigation, and persistence within the existing SwiftUI architecture.
- Handle actor isolation, cancellation, dynamic type, accessibility, and scene lifecycle.

## Acceptance

Build and test preview/device flows for rotation, offline recovery, and long localized content.

## Constraints

- Do not fight platform navigation and accessibility conventions.
