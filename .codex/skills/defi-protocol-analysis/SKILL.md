# Defi Protocol Analysis

## Decisions

- Identify deployed chain/contracts, upgrade authority, oracle dependencies, liquidity, and economic incentives.
- Verify audits against the actual deployed version; inspect admin and liquidation risks independently.

## Acceptance

Report source-backed exposures and unknowns without implying an audit guarantees safety.

## Constraints

- Do not present APY as risk-free yield.
