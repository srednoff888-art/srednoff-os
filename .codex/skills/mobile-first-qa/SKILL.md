# Mobile First Qa

## Decisions

- Test critical workflows at narrow viewports with touch input, virtual keyboard, and realistic network conditions.
- Check safe areas, target sizes, focus, scrolling, overflow, and orientation changes.

## Acceptance

Capture reproducible mobile defects and distinguish browser emulation from device evidence.

## Constraints

- Do not assume desktop layouts automatically work on mobile.
