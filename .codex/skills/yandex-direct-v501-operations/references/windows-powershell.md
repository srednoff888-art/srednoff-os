# PowerShell и кодировки

- Сохранять PowerShell-скрипты с кириллицей в UTF-8 с BOM, если они исполняются PowerShell 5.1.
- Не использовать `$pid` как пользовательскую переменную: это read-only встроенное имя.
- Не интерпретировать `@($null).Count` как отсутствие значения: он равен 1. Проверять сырой ответ или явный признак присутствия.
- Для проблемных ответов с кириллицей читать байты и явно декодировать UTF-8 (`RawContentStream` и `Text.Encoding.UTF8`).
- Если операция зависит от JSON `null`, проверить сериализованный запрос до отправки: `ConvertTo-Json` для хэш-таблиц может изменить намеренную структуру.
