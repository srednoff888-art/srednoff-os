# App Store Testflight Release

## Decisions

- Confirm bundle ID, signing, entitlements, build number, distribution group, and current submission requirements.
- Separate uploading a build from enabling testers or submitting to production review.

## Acceptance

Verify processing status and install a test build; disclose untested store/device steps.

## Constraints

- Do not submit apps or change store metadata without explicit confirmation.
