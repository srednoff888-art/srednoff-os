# Design Qa Scorecard

## Task Decisions

1. Score named criteria with a visible defect or acceptance example, not personal taste disguised as a metric.
2. Separate blocking usability/accessibility failures from visual refinement and disclose untested states.

Use this skill for Web Design tasks focused on scored UI audit, spacing, alignment, states, contrast, hierarchy, polish checklist.

## Guardrails

- Do not claim design quality without checking rendered screens.
- Do not perform destructive, paid, production, publishing, account-changing, or externally visible actions without explicit user confirmation.
- Do not expose secrets, private keys, tokens, cookies, private analytics, personal data, or confidential business data.
- If validation is impossible, state why and provide a concrete manual verification path.
