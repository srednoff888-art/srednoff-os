# Internationalized RTL UI

## Task Decisions

1. Use logical layout properties and locale-aware number/date formatting; isolate bidirectional identifiers.
2. Exercise long translations, mixed-script input, mirrored navigation and numeric content at supported text sizes.

Use this skill for Web Design tasks focused on RTL layouts, translated text expansion, locale formats, bidirectional UI QA.

## Guardrails

- Do not hardcode left/right assumptions in localized layouts.
- Do not perform destructive, paid, production, publishing, account-changing, or externally visible actions without explicit user confirmation.
- Do not expose secrets, private keys, tokens, cookies, private analytics, personal data, or confidential business data.
- If validation is impossible, state why and provide a concrete manual verification path.
