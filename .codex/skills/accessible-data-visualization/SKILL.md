# Accessible Data Visualization

## Decisions And Evidence

1. Identify the question the chart answers and expose useful text/data alternatives, units and non-color encodings.
2. Test keyboard access, focus/selection feedback, contrast and a representative screen-reader reading path.

## Boundary

A long alt string or hidden raw table is not automatically an equivalent usable analysis experience.
