# Three Vs Babylon Vs Model Viewer

## Task Decisions

1. Choose model-viewer for straightforward inspection/AR, and an engine only for interactions or rendering requirements it actually enables.
2. Compare asset support, device fallback, accessibility and lifecycle cost with a task-sized proof rather than engine popularity.

Use this skill for 3D Web work focused on choose the simplest correct 3D stack: model-viewer, React Three Fiber, Three.js, Babylon.js, WebGPU, or no 3D.
