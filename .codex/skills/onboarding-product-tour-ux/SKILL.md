# Onboarding Product Tour UX

## Task Decisions

1. Connect onboarding steps to the first useful product outcome and allow skip/resume without blocking returning users.
2. Test interrupted setup, missing permissions and accessible focus instead of measuring only tour completion.

Use this skill for Web Design tasks focused on activation, walkthroughs, checklists, progressive disclosure, first-run UX.

## Guardrails

- Do not block experienced users with mandatory tours.
- Do not perform destructive, paid, production, publishing, account-changing, or externally visible actions without explicit user confirmation.
- Do not expose secrets, private keys, tokens, cookies, private analytics, personal data, or confidential business data.
- If validation is impossible, state why and provide a concrete manual verification path.
