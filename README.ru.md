# Srednoff OS для Codex

Автор: **Ivan Srednoff (Иван Среднёв)**. [Srednoff.agency](https://Srednoff.agency).

Srednoff OS хранит инженерные инструкции, выбирает релевантные workflows и
проверяет состояние установки. Основные направления: код, дизайн, реклама,
3D-моделирование, сайты и UI/UX.

## Обновление октября 2026

| Изменение | Результат |
|---|---|
| Сопоставление с Claude OS | Перенесены 17 отдельных MIT workflows и полезные механизмы |
| Новые workflows | React, Playwright CLI, Blender, Google Ads MCP и evals обновления моделей |
| Качество каталога | Сужены 192 триггера, предметно переработаны 105 workflows |

| Сохранность правок | Hash каждого установленного файла; конфликт вместо перезаписи |
| Проверки | Индекс, ссылки, тесты установщика, реальные результаты селектора и CI |

## Установка Выборки

```powershell
python scripts/skill_catalog.py profile --project . --brief "Задача проекта" --max-skills 12 --install
```

Библиотека остаётся в `.codex/skills`, а полный каталог capabilities читают
скрипты. В контекст попадают выбранные instructions. Кэш выбора не запрещает
подключить другой нужный skill.

Приватные коннекторы и учётные данные не входят в публичный пакет. Новые MCP
workflows сами по себе не подключают аккаунты и не запускают внешние серверы.

Зелёный CI подтверждает конкретные технические проверки. Превосходство моделей,
экономия денег и удовлетворённость пользователей требуют отдельных измерений.
