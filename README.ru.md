# Srednoff OS для Codex

Автор: **Ivan Srednoff (Иван Среднёв)**. [Srednoff.agency](https://Srednoff.agency).

Srednoff OS хранит инженерные инструкции, выбирает релевантные workflows и
проверяет состояние установки. Основные направления: код, дизайн, реклама,
3D-моделирование, сайты и UI/UX.

## Обновление Ноября 2026

Проверен весь каталог: **416 skills**, **20 новых**; для **196 существующих**
добавлены предметные решения и критерии проверки. Основной упор: код, дизайн,
сайты, UI/UX, реклама и 3D-моделирование.

| Функция | Польза |
|---|---|
| Компактное обнаружение | Полный каталог доступен селектору, но не объявляется целиком активным |
| Безопасное обновление | Сравнение с предыдущим пакетом, backups, сохранение личных правок |
| Источники | 47 карточек, 11 закреплённых GitHub revisions; проверка лицензий нужных файлов |
| Контроль MCP | Различия инструментов/схем требуют ревью; readOnlyHint не выдаёт разрешение |
| Бюджет профиля | Лимит символов выбранных SKILL.md, без обещаний точного подсчёта токенов |
| Design brief | Опциональное сохранение короткого брифа в проект |

Тесты каталога/установки: **54/54**. Селектор: **61/61**. Структурная проверка:
**416/416**. Независимый benchmark качества моделей не выполнялся.

Компактный режим обратим: исходные манифесты сохраняются, личные skills не
удаляются. После миграции нужно обновление обнаружения или новая сессия;
уже прочитанный контекст текущего чата невозможно стереть изменением файлов.

## Установка Выборки

```powershell
python scripts/skill_catalog.py profile --project . --brief "Задача проекта" --max-skills 12 --install
```

Библиотека остаётся в `.codex/skills`, а полный каталог capabilities читают
скрипты. В контекст попадают выбранные instructions. Кэш выбора не запрещает
подключить другой нужный skill.

Приватные коннекторы и учётные данные не входят в публичный пакет. Новые MCP
workflows сами по себе не подключают аккаунты и не запускают внешние серверы.

Зелёный CI подтверждает конкретные технические проверки. Превосходство моделей,
экономия денег и удовлетворённость пользователей требуют отдельных измерений.
